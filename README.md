# AIv2

LINK: https://aiv2gl.streamlit.app/

Uses Streamlit Community Cloud and Cloudflare Workers API.

Uses Gemma 4, IBM Granite 4, and GPT-OSS. Supports image uploads, Whisper speech recognition, image compression, and DuckDuckGo web search.

The frontend uses the supplied Ybouane LiquidGlass 1.0.3 WebGL renderer for the composer, chat bubbles, and dropdown menus. See `README-LIQUID-GLASS.md` for the shared-scene and frosted-material integration details.
